# Zurich Web Developer Assessment

A secure Next.js implementation of the Zurich Web Developer take-home assessment.

## Status

Implementation in progress.

## Principles

- Next.js App Router with server-side business logic
- Google OAuth authentication
- Redux Toolkit for client application state
- Server-side pagination and filtering of the ReqRes dataset
- Privacy-first email masking/reveal flow
- Reusable, configurable layout components
- Automated unit and integration tests
